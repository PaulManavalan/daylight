# Connected Today overview

`/day/briefing` is a read-only, browser-local overview of the Notion daily planner, meals, selected training, SAT records and imported calendar snapshots. It refreshes on opening, focus, storage changes and each minute while mounted. It is not an automatic pre-wake background briefing or AI-written synthesis.

Only an explicitly approved timetable for the current device-local date with matching calendar and training revisions supplies the next activity. Changed or malformed data prompts review instead of presenting an obsolete schedule as current. Time passing never checks off an assignment or workout. Sample plans retain a visible sample label. The Notion read time stays visible and a saved snapshot is not represented as live synchronization.

The daily Catholic reading link uses the displayed local date and points to the USCCB source; no Scripture text is copied. News retrieval and licensed synthesis remain open requirements. Live Google/Apple account authorization and multi-device persistence also remain incomplete; file imports must not be described as live connections.

Focused SAT and personal records are the local preview records, which may differ from an authenticated full-workspace account. This checkpoint reuses the daily session schema with the planner to reduce parsing drift. Tests cover approval, same-day checks, changed sources, malformed records and preservation of unfinished work.
