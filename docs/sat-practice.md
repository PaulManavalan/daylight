# SAT practice checkpoint

`/day/sat` provides ten original, versioned Daylight questions covering linear equations, quadratics, ratios/percentages, transitions, sentence boundaries and evidence. It is a starter collection, not an official SAT simulation, calibrated adaptive test, score predictor or comprehensive preparation program.

Short sets prioritize unseen questions, then previously missed questions. Each explicit answer submission saves the answer, question version, timestamp and elapsed wall-clock seconds in the existing local-demo SAT store. Elapsed time includes time away from the tab; displaying it is optional and there is no forced time limit. Unfinished questions are not saved as attempts. Explanations follow submission. Incorrect answers can be added explicitly to the existing error log; repeat clicks do not duplicate the same error note.

Skill summaries include repeated exposures, which may reflect familiarity rather than transfer to new problems. Existing scores, goals and errors remain separate. Small-set accuracy is never converted to a scaled SAT score or mastery claim. The full workspace still provides manual score entry and scheduling; this checkpoint does not automatically mark a scheduled review complete.

SAT backups and recovery use the existing versioned schema. Older records receive an empty attempt array. Stale writes, malformed records and storage failures preserve prior data. Individual answer removal asks for confirmation; it leaves score and error records intact. Data is browser-local, not account-synchronized. The focused SAT page uses the local-demo store and labels it separately from authenticated workspace records.

The numeric answer keys have independent substitution/arithmetic checks. Unit coverage includes migration, stale writes, grading validation, repeated attempts and question selection. Browser coverage includes submission, explanations, explicit error logging, a complete set, export/reload, existing full-workspace flows and mobile layout. Broader question review and more items across the complete SAT skill map remain required.

Official full-length practice is linked to [College Board's Bluebook practice](https://satsuite.collegeboard.org/practice/practice-tests/bluebook), verified November 21, 2026. No official question bank content is copied or scraped, no provider results are automatically imported, and no paid service is enabled.
